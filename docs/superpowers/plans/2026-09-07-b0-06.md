> **For agentic workers:** Use superpowers:subagent-driven-development for the independent API task and review; execute the coupled scheduler/source changes together.

**Goal:** Make the existing B0 business loop run continuously with durable interval dispatch and lossless event wakeups.

**Architecture:** Keep Mission ScheduleRow; add source_schedules keyed by source run and job type for sync_events/check_freshness. Dispatch short per-store transactions using the database clock and fixed anchors; retain the existing worker and lease-fenced publication. Source jobs coalesce under the store lock, with one active job per source/type and durable follow-up requests.
